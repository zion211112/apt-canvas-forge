# Apt Canvas Forge

APT-LABS — The ledger of useful work. Scaffold the APT-LABS layout, design tokens, and navigation:
- Design tokens & aesthetics: Dark canvas (#07090d), jade signal (#35d9a4), amber output (#e8b84b), monospace/golden-ratio typography accents, 8px spacing grid.
- Top navigation bar: Brand / status indicator, view toggles (Kemet OS, Workspace), and module tabs (Kernel, Network, Builds, Operations, Research), plus user role indicator.
- Three-pane workspace layout:
  - Left: Explorer tree navigation with collapsible modules, search, and page selector.
  - Center: Module surface / viewport area.
  - Right: Inspector panel with action triggers (mint, audit, fork).
- Bottom status bar with mode and quick metrics.
- Command palette trigger (⌘K / ⌘P) and collapsible chat agent drawer.
